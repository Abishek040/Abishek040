## Selected Projects

### 👓 AI-Powered Smart Glass for Visually Impaired Users
Wearable embedded assistive device for real-time obstacle and object detection, combining ESP32-CAM video capture with YOLO-based object detection and ultrasonic distance sensing, with audio feedback via DFPlayer Mini.
**Hardware:** ESP32-CAM, Arduino Nano, ultrasonic sensor, DFPlayer Mini
**Software:** Embedded C, Python, YOLO/OpenCV
**Testing:** Bench-tested detection accuracy and sensor response across obstacle distances and lighting conditions; validated audio feedback latency
**Status:** Working prototype — repository not yet published
**Repository:** _coming soon_

### 🗳️ Fingerprint Voting System
Secure biometric voting terminal using a fingerprint sensor and microcontroller to prevent duplicate votes, with LCD, buzzer, and LED status indicators.
**Hardware:** Arduino UNO, fingerprint sensor module, I2C LCD, push buttons, buzzer, LEDs
**Software:** Embedded C (Arduino IDE)
**Testing:** Validated fingerprint match/reject accuracy and duplicate-vote prevention across repeated functional test cycles
**Status:** Completed prototype
**Repository:** [Biometric-Fingerprint-Voting-System](https://github.com/Abishek040/Biometric-Fingerprint-Voting-System-Arduino-Based-Secure-Voting)

### 💡 LiFi Data Transfer System
Light-based wireless data transmission link as an alternative to RF communication — a smartphone torch (Morse code) as transmitter, an LDR + Arduino Nano as receiver.
**Hardware:** Arduino Nano, LDR sensor module, buck converter
**Software:** Embedded C (Arduino IDE)
**Testing:** Verified data integrity and transmission reliability across varying distances and ambient light interference
**Status:** Completed prototype
**Repository:** [Lifi_Data_Transfer_System](https://github.com/Abishek040/Lifi_Data_Transfer_System)

### 🧠 Microsoft Student Ambassador Quiz Platform
Real-time interactive quiz platform built for a campus technical event, with live scoring and a leaderboard, tested under concurrent multi-user load during the event.
**Software:** JavaScript, HTML, CSS
